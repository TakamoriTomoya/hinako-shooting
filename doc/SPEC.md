# ひなこシューティング - 仕様

## コンセプト
「ひなこタワーバトル」と同じひなこの写真を使った、宇宙でひなこを撃って倒す縦スクロールシューティング。
背景は宇宙（CSSのグラデーション＋canvasで描く流れる星とチーズの惑星）。暗い背景に写真が溶けこまないよう、ひなこには白いふち（ステッカー風）を付けている。

## 対象プラットフォーム
- Web（PC / スマホブラウザ）、ひとりで遊ぶ（オンライン通信なし）

## ゲームルール
1. 自機（戦闘機）は自動で弾を撃ち続ける。プレイヤーは動かすだけ
2. 全3ステージ。各ステージは「STAGE n」表示 → ザコ戦 → 「WARNING」 → ボス（でか○○ひなこ）の順に進む
   - ザコ戦が決まった時間（STAGE 1: 30秒 / 2: 35秒 / 3: 40秒）続くとボスが降りてくる（倒した数は関係ない）。残り時間は画面に出さない
   - ザコ戦の間、時間が経つほどザコの出てくる間隔が短くなり、数が増えていく。STAGE 1は始めはゆっくり少なめで、後半も増やしすぎない
   - ボス戦中も、ボスを倒すまでずっとザコが出てくる。STAGE 1・3は編隊が数秒おきに、STAGE 2は上・左右の上の方・左右の下の方から入ってきて自機めがけて突っ込んでくるザコが1秒くらいおきに1体ずつ
   - ボスを倒すと「STAGE CLEAR!」の後、次のステージへ。ライフ・パワー・スコアは引き継ぐ
   - 先のステージほど、ザコが硬く弾が速くなり、ボスのHP・弾の数も増える
   - ボスは毎ステージちがうひなこ
   - STAGE 2のボスだけ、中くらいのひなこ2体（HPは別々。どちらから倒してもいい）
   - STAGE 3はザコ戦・ボス戦ともにザコがとても多い
3. STAGE 3のボスを倒すと「STAGE CLEAR!」の後、ボーナスステージ（「BONUS STAGE」表示）になり、それが終わればクリア
   - 攻撃してこない（弾を撃たず、体に当たってもやられない）ザコひなこが、30秒間どんどん押し寄せてくる
   - 5〜7体が一列に並んだ群れが0.3〜0.55秒おきに、上・下・左・右のどれかから入ってきて、ゆらゆら揺れながら反対側へ横切っていく（全部で400体くらい）
   - HPは20（ふつうのザコよりずっと硬い）。1体200点。アイテムは落とさない
   - 押し寄せ終えたら、残ったザコがいなくなる（最大5秒）のを待ってクリア
4. 敵の弾・敵の体に当たるとライフが1減る（ライフ3）。当たり判定は自機中心の白い点だけ
   - やられた直後は2秒無敵、画面上の敵の弾は消え、パワーが1段階下がる
5. ライフが0になったらゲームオーバー

## スコア
- ザコ: 100点 / ボスに弾を当てる: 1ダメージにつき10点（強い弾は1発30点）
- ボス: 5000点 × ステージ番号（2体の時は1体につきその半分）
- クリア時: 残りライフ × 1000点
- ボーナスステージのザコ: 200点

## 敵
- ザコ: まっすぐ / くねくね / 横から弧を描いて横切る / 止まってから自機めがけて突っ込む / 止まってビームを3連射する / 止まってビームを1発撃つ / 止まって真下へレーザーを撃つ / 横から一列に並んで入ってきて横切る（片側から5体、または左右から4体ずつ高さをずらしてすれちがう。STAGE 2はどちらも3体ずつ）、の9種類の編隊。
  - ビームを3連射するザコは一旦どのステージにも出さない
  - STAGE 2・3には、左右の下の方から1体ずつ横に入ってきて止まり、ビームを1発ずつ撃つザコも出てくる（撃ち終わると入ってきた側へ帰っていく）
  - STAGE 1には、さらにレーザーを撃つザコ・突っ込んでくるザコ・下の方からビームを撃つザコも出てこない（6種類の編隊）
  - STAGE 3のザコ戦は、前（上）から3割・左右から4割・下の方（左右の下の方から横に入ってくる）から3割くらいの割合で出てくる。
    左右の上の方・下の方から入ってきて、止まってから自機めがけて突っ込んでくるザコも出る
  - ふつうのザコは、ときどき自機を狙って赤いビームを1発撃つ
  - ビームのザコは、降りてきて止まり、口元に赤い光をためて(予告)から自機めがけて赤いビームを撃つ。
    左右に1体ずつ出て3連射するものと、横に3体並んで1発ずつ撃つものがいる。
    しばらくすると上へ帰っていく。HPはふつうのザコより1多い
  - レーザーのザコは、降りてきてぴたっと止まり、撃つ場所に点滅する細い線を出して(予告)から、
    口元から真下へ一直線に太いレーザーを伸ばす。レーザーは2秒で止まり、
    ザコは上へ帰っていく（倒すとその時点でレーザーも消える）。HPはふつうのザコより1多い
- ボス（STAGE 1）: 大きなひなこ1体。「扇状の狙い撃ち(赤)」「全方向リング(水色)」「うずまき(緑)」の3パターンのビームを順に繰り返し、
  HPが半分を切ると弾が増えて速くなる。体の形に沿って燃え上がる紫の炎のオーラと、立ちのぼる火の粉をまとい、
  HPが半分を切るとオーラが赤く大きく速く揺らめく
- ボス（STAGE 2）: 中くらいのひなこ2体。HPは別々（2体の合計がこのステージのボスのHP）で、HPゲージも1体ずつ左右に並べて出す。
  倒した方はオーラが消える。
  それぞれ自分の側（左半分・右半分）の上の方を不規則に動き回り、ときどき3方向の弾を撃つ（弾は少なめ）。
  - 十字砲火: 6〜8秒おきに、2体が左右対称の位置（左右の上の方）へ動いて口元に水色の光をため（予告）、
    2.6秒ほど同時に斜め下へ水色の弾を連射する。撃つ向きを左右対称に振るので、2体の弾がX字に交差して、
    そのすき間が上下に動く。撃っている間はふだんの弾は撃たない。1体を倒すと十字砲火はしなくなる
  - 1体を倒すと、残った1体が怒る（オーラが赤くなる）。画面の上の方全体を速く動き回り、5方向の速い弾をたくさん撃つ
  - ボスは突っ込んでこないかわりに、上・左右の上の方・左右の下の方から入ってきて、止まってから自機めがけて突っ込んでくるザコが次々に出てくる
- ボス（STAGE 3）: 大きなひなこ1体。STAGE 1のボスと同じ3パターンの弾を撃ちながら、4秒ほどごとに
  その場で震えて（予告）から自機の方へ向きを変えながらゆっくり迫ってきて（体当たり）、元の位置へ戻る。
  HPが半分を切ると体当たりの間隔が短く・速くなる。
  - バリア: 戦い始めて5秒ほどで、まわりに水色に光る丸いバリアを張る。張っている間はボスに弾が効かず、
    バリアに当たった弾はすべて受け止められる。バリアに90ダメージ当てると「BREAK!」で壊れ、10秒後にまた張る。
    残りが少なくなるとバリアが薄くなってちらつく
- どのひなこが出るかは毎回ランダム（全16種類、`src/lib/enemyCatalog.ts`）

## アイテム
- パワーアップ(光る金色の星): 倒したザコが落とす。どのステージでも1ステージで3つくらい出る。
  STAGE 1は運で差がつかないよう、確率ではなく決まったタイミングで必ず3つ出す（ザコ戦の35%・75%を過ぎて最初に倒したザコ、ボス戦が始まって15秒を過ぎて最初に倒したザコ）。
  STAGE 2・3は確率で、ザコが多いステージほど低くする（2: 1.8% / 3: ザコ戦1%・ボス戦中2%）。拾うと弾が 1発 → 2発 → 4発（扇状）に増える。
  レベル4: 4発に加えて、ミニ戦闘機2機が自機のまわりをぐるぐる回る。
  ミニ戦闘機は撃たないが、触れた敵の弾を消し、触れたザコにダメージを与える（ボスには効かない）。
  レベル5: さらに、その外側をミニ戦闘機3機が反対回りに回る（ミニ戦闘機は全部で5機）。
  レベル6: さらに、大きなオレンジの爆弾（ダメージ3）をまっすぐ、ふつうの弾より遅い間隔で撃つ。
  当たると爆発して、まわりのザコにもダメージを与える。
  レベル7: さらに、オレンジの爆弾を左右ななめ前の2方向にも撃つ。
  レベル8: さらに、自機から全方向（12方向）へ弱いビーム（ふつうの弾の半分のダメージ）を、0.45秒おきに輪のように撃つ。
  レベル9: さらに、3秒おきに自機から衝撃波の輪が画面の端まで広がり、通ったところの敵の弾を消して、ザコに3ダメージを与える
  （レーザーとボスには効かない。全9段階）。
  最大の時に拾うと500点
- ハート: 拾うとライフが1回復（最大3）。満タンの時は1000点。ボス自身は落とさない
  - どのステージでも1ステージで2.5個くらい（ザコ戦で1.5個・ボス戦中で1個）出るように、ザコが多いステージほど確率を低くする
  - ザコ戦のザコ: STAGE 1は1.5%、STAGE 2は1.2%、STAGE 3は0.75%（めったに出ない）
  - ボス戦中に出てくるザコ: STAGE 1は2%、STAGE 2は2.9%、STAGE 3は2%

## 音
- BGM・ジングル: SketchyLogic「NES Shooter Music (5 tracks, 3 jingles)」（CC0、OpenGameArt）。`public/audio/` にAACで置いている
  - ホーム: Map / STAGE 1〜3: Venus・Mars・Mercury / ボス戦: BossIntro → BossMain をくり返し
  - 「STAGE n」表示: Intro Jingle / STAGE CLEAR: Warp Jingle / 全クリア: Win Jingle / WARNING中とゲームオーバー後は曲なし
- 効果音: Web Audioでコードから合成（弾・命中・撃破・被弾・アイテム・WARNING・ボス撃破・ゲームオーバー）
- ブラウザの決まりで、画面を一度触るまで音は出ない。ほかのタブに移ると止まる
- 左下のボタンで音のオン/オフ（端末に保存）

## 操作
- スマホ: 画面のどこかをドラッグ（指を動かした分だけ自機が動く。指で自機が隠れないように）
- PC: 矢印キー / WASD（マウスのドラッグでも可）

## 技術構成
- React + TypeScript + Vite + Tailwind CSS（タワーバトルと同じ構成）
- ゲーム本体（Canvas描画・入力・敵や弾・当たり判定）はReactに依存しない`ShootingEngine`クラス（`src/lib/engine.ts`）に集約し、
  Reactは画面遷移・スコア表示などUIの薄いシェルとして被せる
- 調整用の数値はすべて`src/lib/constants.ts`。ステージごとの難しさは`STAGES`（足せばステージが増える）
- 写真は`public/images/`。毎フレーム多数描くため、元画像（約1500px高）を480px高に縮小して置いている
- ハイスコアは端末のlocalStorageに保存
- URLに`?debug`を付けると`window.shootingEngine`からエンジンを触れる（動作確認用）
- 開発用: 開発サーバー（`npm run dev`）か、URLに`?dev`を付けた時だけ、スタート画面に「開発用」の欄が出て、
  始めるステージ（1〜3・ボーナス）、ザコ戦から始めるかボス戦から始めるか、戦闘機の攻撃レベル（1〜9）を選んでスタートできる。
  ボス戦からを選ぶと、「STAGE n」の後すぐに「WARNING」になる。ステージでボーナスを選ぶと「BONUS STAGE」から始まる（ボーナスにはザコ戦・ボス戦がないので、「始める所」の欄は出ない）。結果画面の「もう一度」も同じ設定で始まる。
  STAGE 1のザコ戦・レベル1以外で始めた回はハイスコアに残さない
